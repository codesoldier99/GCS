# 中影智能 — 无人机培训地面站

面向无人机培训学校**学员**的桌面地面控制站（GCS），连接 **APM / ArduPilot** 飞控（参考硬件：翎客 X6PRO）。
界面配色取自**标志(Peugeot) i-Cockpit** 汽车仪表方案：深邃蓝黑底 + 冰蓝荧光 + 铬银描边。

> 详细开发约定见 [`CLAUDE.md`](./CLAUDE.md)。参考资料：`GCS.pdf`、`FLIGHT CONTROL.pdf`。

## 快速开始

```bash
npm install     # 首次安装依赖
npm run dev      # 启动开发窗口（热重载）
```

首次安装若卡在 Electron 二进制下载，用国内镜像：

```bash
ELECTRON_MIRROR="https://registry.npmmirror.com/-/binary/electron/" npm install
```

Node 需 ≥ 20。

## 连接方式

启动后进入主菜单 → 任意飞行入口 → 点击右上角连接胶囊，选择：

- **仿真**：无需硬件，内置 SITL 式飞行模拟。进入飞行界面点「一键演示」即自动起飞绕圈。
- **串口**：连接 X6PRO/APM，波特率默认 115200。
- **UDP**：监听本地端口（ArduPilot SITL 默认发往 `127.0.0.1:14550`）。
- **TCP**：连接 `host:port`（SITL 默认 `127.0.0.1:5760`）。

## 已实现（里程碑 3 · 装机向导 + 飞控调参）

## 已实现（里程碑 4 · CAAC 训练 + 日志回放）

- **绕八字飞行考试**：布设两电子桩（点击地图 / 以起飞点自动布桩）→ 绘制两圆与理想八字路径 →
  开始考试 → **实时评分**（完成圈数、最大横向偏差、平均偏差、高度保持、用时、合格判定）。内置「仿真演示：自动绕八字」。
- **飞行日志回放**：自动录制飞行会话，时间轴回放（播放/暂停/0.5–8× 变速/拖动），仪表与地图轨迹同步；支持 JSON 导入导出。

## 动效与声音

- **环形主菜单**：六个功能以环形排布，鼠标悬停时扇区外扩发光、中心盘联动显示功能详情；
  支持方向键导航与 Enter 选中。外圈刻度与扫描弧呼应姿态球罗盘。
- **界面音效**：Web Audio 振荡器实时合成，不含任何音频文件。悬停、选中、返回、危险操作
  各有独立音色。
- **可配置**：标题栏齿轮 → 界面设置，可开关界面音效、调节界面/告警音量、开启「精简动效」。
  设置本地持久化。
  - 飞行告警音独立于界面音效：即使界面静音，电压/失控等安全告警仍会发声。
  - 教室多机同用时可一键静音；低配笔记本可开「精简动效」。
- 飞行主界面刻意不加装饰动效，避免分散学员注意力。
